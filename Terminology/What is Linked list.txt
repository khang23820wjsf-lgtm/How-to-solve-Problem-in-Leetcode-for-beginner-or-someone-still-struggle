Part 1: Terminology
1. So , what the hell is linked list?
 Unlike a normal list
 Ex: 1 -> 2 -> 3 
 we can find a number by using index like : s[0], s[1],...
 Linked list is a linear data structure in Computer Science
 Each element in here like a node
 Each node stores:
	1. a value
	2. a reference to the next node
 Ex : 1 -> 2 -> 3 -> 4 -> None
 we have : 1 ( val : 1 | next :2) -> .... -> 4 (val : 4 | next: none)
The important thing is that the nodes don't have to be stored
next to each other in memory.

Instead, each node tells us where the next node is.
For example : 
	
current
|
V	
1 -> 2 -> 3 -> 4 -> NULL
if we want to move through the linked list, we will use:
	current = current.next
