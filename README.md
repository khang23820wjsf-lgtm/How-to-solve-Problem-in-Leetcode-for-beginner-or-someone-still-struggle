# 🚀 My LeetCode Journey

> **Learning algorithms one problem at a time.**

This repository contains my solutions, notes, mistakes, and things I learn while solving LeetCode problems.

I'm not trying to write the most optimal solution from the beginning.

Sometimes my code will be ugly.

Sometimes it will be unnecessarily complicated.

Sometimes I'll look at my old code months later and wonder:

> **"What the hell was I thinking?"** 💀

And that's completely fine.

The goal of this repository is to **learn, improve, and keep track of my progress**.

---

## 🎯 Goals

My main goals are:

* Build a strong foundation in Data Structures & Algorithms
* Learn to recognize common problem-solving patterns
* Improve my problem-solving skills
* Understand Time & Space Complexity
* Write cleaner and more efficient code over time
* Keep a record of how my solutions improve

I'm focusing on **understanding the problems**, not just collecting solved badges.

## 🧠 My Approach

I don't expect my first solution to be perfect.

My usual process is:

```text
Understand the problem
        ↓
Try solving it myself
        ↓
Write the first solution
        ↓
Test edge cases
        ↓
Analyze Time & Space Complexity
        ↓
Look for improvements
        ↓
Write down what I learned
```

The first solution doesn't have to be beautiful.

**It just has to teach me something.**
