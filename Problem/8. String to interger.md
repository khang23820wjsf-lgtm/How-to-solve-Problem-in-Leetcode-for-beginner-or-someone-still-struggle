# Problem 8 — String to Integer (atoi)

## Problem

Implement the `myAtoi(string s)` function, which converts a string to a 32-bit signed integer.

The algorithm for `myAtoi(string s)` is:

1. **Whitespace:** Ignore leading whitespace (`" "`).
2. **Signedness:** Determine the sign by checking if the next character is `+` or `-`. Assume positive if neither is present.
3. **Conversion:** Read the integer by skipping leading zeros until a non-digit character is encountered or the end of the string is reached. If no digits were read, return `0`.
4. **32-bit range:** The integer must be in the range `[-2^31, 2^31 - 1]`.
   - If the number is smaller than `-2^31`, return `-2^31`.
   - If the number is larger than `2^31 - 1`, return `2^31 - 1`.

> **Note:** The original problem statement contains a typo if it says `[-2^31, 2^31]`. The correct signed 32-bit range is `[-2^31, 2^31 - 1]`.

---

## Approach

This is an **Easy** problem. The main idea is to parse the string manually instead of directly calling `int()` / `stoi()` / `parseInt()`.

### Step 1 — Remove leading/trailing whitespace

In Python, we can use `.strip()`:

```python
s = "    abcdef    "
s = s.strip()

# s == "abcdef"
```

`.strip()` removes whitespace from both the beginning and the end of a string.

For this problem, only leading whitespace matters. Using `.strip()` is still valid because trailing whitespace does not affect the result.

---

### Step 2 — Build the valid numeric part

We create an empty string:

```python
s1 = ""
```

Then iterate from the beginning of the string.

If the first character is `+` or `-`, keep it.

If the character is a digit, keep it.

If the character is neither a sign nor a digit, stop immediately.

For example:

```text
"   -0042abc"
      ↓
"-0042abc"
      ↓
"-0042"
```

In Python, ASCII can be checked with:

```python
ord(s[i]) >= 48 and ord(s[i]) <= 57
```

because:

```text
'0' → 48
'1' → 49
...
'9' → 57
```

Python also provides:

```python
s[i].isdigit()
```

but using `ord()` makes the ASCII logic explicit.

---

### Step 3 — Check whether we actually found a number

These cases contain no valid integer:

```text
""
"+"
"-"
```

So:

```python
if s1 == "" or s1 == "+" or s1 == "-":
    return 0
```

---

### Step 4 — Determine the sign

Start with:

```python
sign = 1
```

If the first character is `-`:

```python
sign = -1
s1 = s1[1:]
```

If the first character is `+`:

```python
s1 = s1[1:]
```

For example:

```text
"+345"
  ↓
"345"
sign = 1
```

and:

```text
"-345"
  ↓
"345"
sign = -1
```

> Important: We modify `s1`, not `s`. The original version accidentally used `s = s[1:]` in the negative case.

---

### Step 5 — Convert digits into an integer

Instead of using `int(s1)`, construct the number manually:

```python
num = 0

for digit in s1:
    num = num * 10 + (ord(digit) - ord("0"))
```

Why does this work?

For `"345"`:

```text
num = 0

3:
0 * 10 + 3 = 3

4:
3 * 10 + 4 = 34

5:
34 * 10 + 5 = 345
```

This is the standard way to construct a number digit by digit.

---

### Step 6 — Apply the sign

```python
num *= sign
```

So:

```text
"345" + sign = 1  →  345
"345" + sign = -1 → -345
```

---

### Step 7 — Clamp to the 32-bit signed integer range

The valid range is:

```text
[-2^31, 2^31 - 1]
```

which is:

```text
[-2147483648, 2147483647]
```

In Python:

```python
if num < -2**31:
    return -2**31
elif num > 2**31 - 1:
    return 2**31 - 1
else:
    return num
```

> **Python warning:** `^` is NOT exponentiation. It is bitwise XOR.
>
> Use `2**31`, not `2^31`.

---

# Python

```python
class Solution:
    def myAtoi(self, s: str) -> int:
        # Step 1: Remove whitespace
        s = s.strip()

        # Step 2: Build the valid numeric part
        s1 = ""

        for i in range(len(s)):
            if i == 0 and (s[i] == "+" or s[i] == "-"):
                s1 += s[i]
            elif ord(s[i]) >= 48 and ord(s[i]) <= 57:
                s1 += s[i]
            else:
                break

        # Step 3: No valid number
        if s1 == "" or s1 == "+" or s1 == "-":
            return 0

        # Step 4: Determine sign
        sign = 1

        if s1[0] == "-":
            sign = -1
            s1 = s1[1:]
        elif s1[0] == "+":
            s1 = s1[1:]

        # Step 5: Convert digits to integer
        num = 0

        for digit in s1:
            num = num * 10 + (ord(digit) - ord("0"))

        # Step 6: Apply sign
        num *= sign

        # Step 7: Clamp to 32-bit signed integer range
        if num < -2**31:
            return -2**31
        elif num > 2**31 - 1:
            return 2**31 - 1

        return num
```

# C++

```cpp
class Solution {
public:
    int myAtoi(string s) {
        // Step 1: Skip leading whitespace
        int i = 0;

        while (i < s.size() && s[i] == ' ') {
            i++;
        }

        // Step 2: Determine sign
        int sign = 1;

        if (i < s.size() && (s[i] == '+' || s[i] == '-')) {
            if (s[i] == '-') {
                sign = -1;
            }
            i++;
        }

        // Step 3: Convert digits
        long long num = 0;

        while (i < s.size() && s[i] >= '0' && s[i] <= '9') {
            int digit = s[i] - '0';

            num = num * 10 + digit;

            // Step 4: Clamp to 32-bit signed integer range
            if (sign == 1 && num > INT_MAX) {
                return INT_MAX;
            }

            if (sign == -1 && -num < INT_MIN) {
                return INT_MIN;
            }

            i++;
        }

        return static_cast<int>(num * sign);
    }
};
```

### Why use `long long` in C++?

Because `int` itself is limited to the 32-bit range.

While constructing the number, `num` may temporarily become larger than `INT_MAX`.

Using:

```cpp
long long num = 0;
```

gives us enough room to detect overflow safely before returning an `int`.

# JavaScript

```javascript
var myAtoi = function(s) {
    // Step 1: Remove leading whitespace
    s = s.trimStart();

    let i = 0;

    // Step 2: Determine sign
    let sign = 1;

    if (i < s.length && (s[i] === '+' || s[i] === '-')) {
        if (s[i] === '-') {
            sign = -1;
        }
        i++;
    }

    // Step 3: Convert digits
    let num = 0;

    while (
        i < s.length &&
        s.charCodeAt(i) >= 48 &&
        s.charCodeAt(i) <= 57
    ) {
        let digit = s.charCodeAt(i) - 48;

        num = num * 10 + digit;

        // Step 4: Clamp to 32-bit signed integer range
        if (sign === 1 && num > 2147483647) {
            return 2147483647;
        }

        if (sign === -1 && -num < -2147483648) {
            return -2147483648;
        }

        i++;
    }

    return num * sign;
};
```

# Complexity

Let `n` be the length of the input string.

### Time Complexity

```text
O(n)
```

We scan through the string at most once.

### Space Complexity

For the Python version using `s1`:

```text
O(n)
```

because we construct another string.

The C++ and JavaScript versions above parse the number directly and use:

```text
O(1)
```

additional space.

# Important Lessons

1. `.strip()` removes whitespace from both ends of a string.
2. ASCII digits range from `48` (`'0'`) to `57` (`'9'`).
3. `ord(digit) - ord("0")` converts a digit character into its numeric value.
4. Build a number using:

```text
num = num * 10 + digit
```

5. In Python, `**` is exponentiation; `^` is XOR. # i use it because i want everyone to understand it easily
6. The 32-bit signed integer range is:

```text
[-2^31, 2^31 - 1]
```
7. A more advanced solution can parse the string directly without creating `s1`, which reduces extra memory usage.
